# Star Investigator — License Control Center (Owner Server)

**PRIVATE OWNER APPLICATION** — do not include in customer distributions.

## Overview
Central licensing authority and admin dashboard. It creates Ed25519-signed
hardware entitlements, enforces device seat limits, tracks activation events,
and manages remote license renewals.

## Quick start (local)
1. Install dependencies: `pip install -r requirements.txt`
2. Set environment variables (see below), then run:
   `gunicorn owner_app:app --bind 0.0.0.0:5050` (or `python owner_app.py`).
3. Open `http://127.0.0.1:5050/login` and sign in as `owner`.

## Configuration (environment variables)
| Variable | Purpose |
|---|---|
| `OWNER_SECRET_KEY` | Flask session signing secret (set to a long random value) |
| `OWNER_INITIAL_PASSWORD` | Password for the first `owner` account (change it after login) |
| `OWNER_ED25519_PRIVATE_KEY_B64` | Base64-encoded PKCS#8 Ed25519 private key used to sign entitlements |
| `PORT` | Port injected by Render/WSGI host |
| `OWNER_PORT` | Local development port (default 5050) |

If `OWNER_INITIAL_PASSWORD` is not set, a one-time random password is generated
and written to `data/INITIAL_OWNER_PASSWORD.txt` (never committed).
If `OWNER_ED25519_PRIVATE_KEY_B64` is not set, a new key pair is generated in
`data/keys/` — this invalidates any licenses signed with a previous key.

## Deploy to Render
`render.yaml` defines a free Python web service. Blueprints read that file
automatically when you connect this repo in Render.

1. Make this repository **private** before exposing the admin dashboard.
2. Create the Web Service from `render.yaml`.
3. In Render dashboard, set these secret env vars (do not put them in git):
   - `OWNER_ED25519_PRIVATE_KEY_B64` — base64 of your PKCS#8 private key PEM.
   - `OWNER_SECRET_KEY` and `OWNER_INITIAL_PASSWORD` are auto-generated by the
     blueprint with `generateValue`, but you may override them.
4. Note: the free plan has an ephemeral filesystem, so `data/` (DB + keys) is
   reset on restart. Add a paid persistent disk mounted at
   `/opt/render/project/src/data`, or migrate to managed Postgres, before
   using this for real customers.

## Features
- Summary metrics for licenses, seats and audit events.
- License generator (daily/weekly/monthly/yearly/permanent, 1–10+ seats).
- Device registry and slot transfer.
- Audit and security event log.
- REST API: `/api/v1/license/activate`, `/validate`, `/deactivate`.
